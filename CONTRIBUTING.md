# Contributing to MYUNIXLIKEOS

Thank you for your interest in contributing! This project is a 32-bit Unix-like OS built with a focus on clean attribution and open-source growth under GPLv3.

## Requirements

- **Full Legal Name:** Every commit must include the author's full legal name in Latin letters.
- **Licensing:** By contributing, you agree your code will be licensed under GPLv3.
- **Architecture:** All code must be compatible with 32-bit `i686-elf-gcc`.

## Getting Started

1. Fork the repository
2. Set up `i686-elf` cross-compiler toolchain
3. Verify changes with `make clean && make && make run`
4. Create a clean commit with your full legal name

## Areas Needing Help

- GUI support
- Unix command expansion
- Networking support

**Commit format example:** `feat: add feature - Your Full Name`
